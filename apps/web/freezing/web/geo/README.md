# Zip code centres

`zip-centroids.csv.gz` is the latitude and longitude of the middle of each US
zip code, trimmed to those three columns from the US file of the
[GeoNames postal code export](https://download.geonames.org/export/zip/),
licensed under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
The front page's map of where registered contestants live credits GeoNames.
